# Student Mental Health Burnout Analysis

## Project Overview
This project analyzes student mental health,
academic pressure, sleep habits, and burnout
using an interactive Power BI dashboard.

## Tools Used
- Microsoft Power BI
- Data Cleaning
- Data Analysis
- Data Visualization

## Dashboard Highlights
- Total student count
- Average sleep hours
- Average anxiety score
- Average CGPA
- Student burnout distribution
- Burnout by sleep quality
- Burnout by stress level
- Burnout by course and academic year
  
  ## Files Included
- Power BI dashboard (.pbix)
- student mental health dataset
- Dashboard screenshot (.png)

## Objective
To explore patterns in student well-being and
academic burnout through interactive visualizations.
